## Sobre el proyecto

**QrGenerator** es una aplicación que nace de la necesidad de imprimir carteles a instalar en un jardín para que, una vez escaneados con el móvil, el usuario llegara a una página web donde se
mostrarían características, propiedades y datos de interés de la planta en cuestión.

La aplicación está construida utilizando HTML5, CSS3, Javascript y Electron.

## Características principales

* **Experiencia de Usuario:** Únicamente dos botones, listo para generar el código Qr y descargarlo.
* **Transparencia:** El mismo código Qr indica a que recurso apunta para crear seguridad y tranquilidad al usuario.
